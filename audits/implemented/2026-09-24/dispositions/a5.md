## Split of mutation_teeth.py

`mutation_teeth.py` (2099 lines) is now `_mutation_model.py` (types, version, source I/O), `_mutation_operators.py`
(operators, `generate_mutants`), `_mutation_fingerprint.py` (import closure, `fingerprint`), `_mutation_runner.py`
(pytest env/flags, tree kill, `_run_pytest`, `_WarmRunner`, classification) and `mutation_teeth.py` (sweep, cache,
public asserts, `__all__`), each under 1000 lines. Every old name is still importable from `mutation_teeth`.
The sweep looks up `_run_pytest`, `_WarmRunner`, `_classify*` and `generate_mutants` in the `mutation_teeth`
namespace and `fingerprint` reads `mutation_teeth.HARNESS_VERSION`, so existing monkeypatches keep working.
The new files are in the harness-version hash list.
